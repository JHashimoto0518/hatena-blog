## ECSサービスのスケジュールされたアクションを一括削除するスクリプト

Claude に書かせた。

```sh
#!/bin/bash
set -euo pipefail

if [ $# -ne 1 ]; then
  echo "使い方: $0 <resource-id>" >&2
  echo "例: $0 service/your-cluster-name/your-service-name" >&2
  exit 1
fi

RESOURCE_ID="$1"
SCALABLE_DIMENSION="ecs:service:DesiredCount"

mapfile -t ACTIONS < <(aws application-autoscaling describe-scheduled-actions \
  --service-namespace ecs \
  --resource-id "${RESOURCE_ID}" \
  --scalable-dimension "${SCALABLE_DIMENSION}" \
  --query 'sort_by(ScheduledActions, &ScheduledActionName)[].ScheduledActionName' \
  --output text | tr '\t' '\n')

if [ ${#ACTIONS[@]} -eq 0 ]; then
  echo "スケジュールされたアクションはありません。"
  exit 0
fi

echo "対象リソース: ${RESOURCE_ID}"
echo "スケジュールされたアクション一覧:"
for i in "${!ACTIONS[@]}"; do
  printf "  [%d] %s\n" "$((i+1))" "${ACTIONS[$i]}"
done

echo
echo "削除する番号をスペース区切りで入力してください(例: 1 3 4)。"
echo "何も入力せず Enter のみの場合はすべて削除します。'q' でキャンセル。"
read -rp "> " INPUT

if [ "${INPUT}" = "q" ]; then
  echo "中止しました。"
  exit 0
fi

if [ -z "${INPUT}" ]; then
  TARGETS=("${ACTIONS[@]}")
else
  TARGETS=()
  for n in ${INPUT}; do
    if ! [[ "${n}" =~ ^[0-9]+$ ]] || [ "${n}" -lt 1 ] || [ "${n}" -gt "${#ACTIONS[@]}" ]; then
      echo "無効な番号です: ${n}" >&2
      exit 1
    fi
    TARGETS+=("${ACTIONS[$((n-1))]}")
  done
fi

echo
echo "以下のアクションを削除します:"
for t in "${TARGETS[@]}"; do
  echo "  - ${t}"
done
read -rp "本当に削除しますか? (y/N): " CONFIRM
if [ "${CONFIRM}" != "y" ] && [ "${CONFIRM}" != "Y" ]; then
  echo "中止しました。"
  exit 0
fi

for ACTION_NAME in "${TARGETS[@]}"; do
  echo "削除します: ${ACTION_NAME}"
  aws application-autoscaling delete-scheduled-action \
    --service-namespace ecs \
    --resource-id "${RESOURCE_ID}" \
    --scalable-dimension "${SCALABLE_DIMENSION}" \
    --scheduled-action-name "${ACTION_NAME}"
done

echo "削除完了。"
```


## PowerShellで特定フォルダのサイズを確認する

特定パスのサイズを確認するスクリプト。直下のフォルダをサイズの大きい順に一覧表示する。こちらも Claude に書かせた。

ダウンロードフォルダの例。

```ps1
Get-ChildItem "$env:USERPROFILE\Downloads" -Directory | ForEach-Object {
    $size = (Get-ChildItem $_.FullName -Recurse -File -ErrorAction SilentlyContinue | Measure-Object -Property Length -Sum).Sum
    [PSCustomObject]@{ Name = $_.Name; SizeMB = [math]::Round($size / 1MB, 2) }
} | Sort-Object SizeMB -Descending | Format-Table -AutoSize
```
