Claude Code の承認待ちに気づけないことがある。対策としてアイドル時にベルを鳴らすようにした。

## Claude Code の設定

アイドル時にターミナルベルを送信させるようにする。

`.claude/settings.json`

```json:
{
  "preferredNotifChannel": "terminal_bell"
}
```

## 開発コンテナの設定

ベル信号を受け取ったら常に音を出すようにする (デフォルト値の`auto`はスクリーンリーダーが有効な時だけ）。

`.devcontainer/devcontainer.json`

```json:
{
  "customizations": {
    "vscode": {
      "settings": {
        "accessibility.signals.terminalBell": {
          "sound": "on",
          "announcement": "auto"
        }
      }
    }
  }
}
```

開発コンテナのリビルドが必要だったかも。
