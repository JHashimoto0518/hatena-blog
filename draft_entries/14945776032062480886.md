## 開発コンテナ + Claude Codeでアイドル時にベルを鳴らす

Claude Code の承認待ちに気づけないことがある。対策としてアイドル時にベルを鳴らすようにした。

Claude Code の設定で、アイドル時にターミナルベルを送信させるようにする。

`.claude/settings.json`

```json:
{
  "preferredNotifChannel": "terminal_bell"
}
```

VS Code の設定で、ベル信号を受け取ったら常に音を出すようにする (デフォルト値の`auto`はスクリーンリーダーが有効な時だけ）。

開発コンテナを使用しているので、`devcontainer.json`に記述する。

`.devcontainer/devcontainer.json`

```json:
{
  "customizations": {
    "vscode": {
      "settings": {
        "accessibility.signals.terminalBell": {
          "sound": "on",
          "announcement": "auto"
        }
      }
    }
  }
}
```
